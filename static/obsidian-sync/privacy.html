OBSIDIAN SYNC

Privacy Policy

Effective November 15, 2026

Application homeContact the owner

1. Purpose

Obsidian Sync is a personal, non-commercial Google OAuth configuration used by its owner with the open-source GSync Obsidian plugin to synchronize notes and files between a local Obsidian vault and a folder in the owner's own Google Drive. It is not a public online service.

2. Google user data accessed

With the owner's consent, the GSync plugin requests Google Drive scope https://www.googleapis.com/auth/drive. This scope technically allows broad access to the owner's Drive files and metadata. GSync uses the permission to read, create, update, synchronize, and when configured, trash files within the Drive folder selected in the plugin. The synchronization requires file names, metadata and contents, including changes and conflict copies.

3. Use of data

Google Drive data is used for the requested personal file synchronization, including listing the chosen folder, comparing changes with the local vault, uploading and downloading file contents, and handling conflicts and deletions according to GSync settings. The data is not used for advertising, profiling, or AI model training.

4. Transfer, storage and sharing

The installed GSync plugin sends file data directly between the device and Google Drive APIs. This informational GitHub Pages website does not upload, collect, or store synchronized files or notes in a separate application database or backend.

GSync stores Google OAuth credentials and refresh tokens locally in the user's Obsidian plugin data file (.obsidian/plugins/gsync/data.json). Synced notes remain in the local Obsidian vault and in the owner's Google Drive. This configuration does not intentionally share note content with other users or sell user data.

The static callback page is used only during OAuth sign-in. It receives a one-time authorization code from Google in the browser redirect and forwards it to Obsidian using an obsidian:// link. It has no custom server-side processing or storage. GitHub Pages and the user's browser may process requests under their own policies.

5. Retention, access removal and deletion

The owner controls how long files are kept in their Obsidian vault and Google Drive. Deleting synced files may also affect the copy on the other side when deletion synchronization is enabled. The owner may revoke OAuth access at Google Account third-party access. Revocation stops future authorized access but does not automatically delete existing notes or copies. Local credentials can then be cleared from the GSync settings.

6. Security and contact

The owner should not publish or share the GSync local data.json, since its refresh token can allow access to their Google Drive. The OAuth scope grants broader access than the folder ordinarily selected for synchronization.

Questions about this personal configuration may be directed to the GitHub profile of its owner. This policy will be revised if the configuration or handling of user data changes.
