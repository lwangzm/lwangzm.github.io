PERSONAL OAUTH APPLICATION

Obsidian Sync

A personal, non-commercial Google OAuth configuration for synchronizing the owner's Obsidian notes and files with the owner's own Google Drive, using the open-source GSync plugin.

Privacy policyContact the ownerGSync source code

How it works

After the owner approves Google OAuth access, the installed Obsidian plugin communicates directly with Google's authentication and Google Drive APIs. It compares files in the configured folder and the local Obsidian vault to synchronize changes.

This website only provides information about the personal OAuth configuration and hosts an authorization redirect page. The website itself does not perform synchronization, host notes, or offer accounts to the public.

Google Drive access

GSync requests the https://www.googleapis.com/auth/drive OAuth scope. This is a broad permission that technically permits access to files elsewhere in the owner's Google Drive. GSync uses it to find existing files and synchronize within the folder chosen in its settings. The scope is broader than the plugin's configured synchronization folder.

Read the privacy policy for information on what data is accessed, where credentials are stored, and how to revoke access.
